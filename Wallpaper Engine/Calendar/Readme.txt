Memo Calendar displays a yearly calendar, memo markers, and weather.

Memo setup: right-click the project, choose 'Open in Explorer', then create a memo file named for the current year, for example 'Memo-2026.txt'. Each line should use this format: month-day=type=text. Supported types are holiday, event, item. Example: 1-1=holiday=New Year.

Weather setup: enter your IPInfo token and OpenWeather token (tokens can be obtained from www.ipinfo.io and www.openweathermap.org by registering a free account) in the wallpaper properties panel. Use the IP Version option to choose IPv4 or IPv6 for IPInfo location lookup, and Unit to choose Celsius or Fahrenheit.
